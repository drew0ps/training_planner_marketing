Training methods

Top sets and back-off sets

Work up to one heavy set, your top set, then take some weight off and do a few more for volume: your back-off sets. One structure gets you both the heavy exposure strength needs and the work muscles grow on.

Not published yet · 3 min read

Why split the sets

Straight sets, the same weight for every set, are a compromise. Heavy enough to build strength, and the last sets are a grind; light enough for good volume, and you never touch a heavy weight. A top set and back-off sets stop compromising: one set near your best for the day, then lighter sets where you can do good reps in numbers.

The top set is the strength stimulus and your progress marker: it's the number to beat next time. The back-off sets bring the volume, at a weight you can control, when you're warm and the heavy set has primed the lift.

How heavy

  • The top set: a weight you could do for a couple more reps than you'll do. In TrainingPlanner's programs it's usually 1 × 5–7, or a set of 4–6; for strength, a top triple or single by effort.
  • The back-off sets: about 10 to 15 % lighter, for more reps: 2 × 8–10 after a top set of 5–7. The first session's note in the templates says it: "a top set you could do for 7, back-offs about 15 % lighter".
  • By effort: a top set at RPE 8, then back-offs at about 85 % of it, is how Squat · Bench · Deadlift does it.

How they progress

Each kind of set progresses from its own last time. With double progression, the top set climbs from 5 to 7 reps and then goes up a step, and the back-offs climb from 8 to 10 and then go up, each in its own time. The top set usually moves first; the back-offs follow a week or two later. That's fine: the gap between them stays about right on its own.

Some programs take the top set to as many reps as you can, marked with a +: Strength Wave's last set each week, for example. Those reps are a minimum, and a big one is a sign the next wave can be heavier.

Plan them in TrainingPlanner

  1. Open the program's board and tap the exercise.
  2. Under Baseline sets, tap Add sets and pick Top set, then again for Back-off.
  3. Open each to set the number of sets, the reps or a rep range, and the weight. Turn on Last set to failure for an as-many-as-you-can top set.
  4. Drag them into order with Reorder if you added them the other way round.

In the workout the sets come in that order, each labelled. A lighter back-off weight carries on to the next back-off set, and the first set of the exercise gets a warm-up ramp beside it, so you build up to the top set rather than starting cold.
